# the box, from before the deploy kept a manifest. The manifest handles everything from here;
# this list only exists to clear the backlog it cannot see.
#
# THIS IS DATA, NOT CODE, and deliberately so. Three gates assert that a retired script's NAME
# does not appear in any .ps1/.sh - correctly, because a name in a script reads as a caller and
# a stale call is what breaks a boot. A path in a delete list is the opposite of a call, so it
# lives here instead of in Deploy-DayZServer.ps1.
#

# memory-maintained state the manifest exists to replace. Report mode prints exactly what it
# would remove; read that against the real box before the first -Fix.
#
# Shipping always wins over sweeping: a path here that is back in $items is kept, not deleted.
